# Project-on-airport-delay

This repo contains code that **requires** the user to download the following files from the [Harvard flight dataset 2009](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/HG7NV7) in order to run:
* **airports.ccv**
* **carriers.csv**
* **plane-data.csv**
* **variable-descriptions.csv**
* **2001.csv.bz2**
* **2002.csv.bz2**
* **2003.csv.bz2**
